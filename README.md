# Механічна академія циклів Python

Автономний інтерактивний тренажер, створений на основі завантаженої практичної роботи з тем:
- цикл `while`, аналізатор пароля та оператор `break`;
- лічильник чисел, сума й добуток;
- математичний тренажер;
- гра «Вгадай число» та модуль `random`.

## Файли
- `index.html` — 10 інтерактивних вправ, перевірка, пояснення, таймер і генератор звіту.
- `README.md` — ця інструкція.
- `LICENSE` — MIT License.

## Публікація на GitHub Pages
1. Створіть репозиторій на GitHub.
2. Завантажте файли з архіву в корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** виберіть **Deploy from a branch**.
5. Вкажіть `main` та `/ (root)`, натисніть **Save**.
6. Сайт буде доступний за адресою `https://USERNAME.github.io/REPOSITORY/`.

## Можливості
- 10 завдань різних типів: одна/кілька відповідей, пропуски, відповідність, аналіз коду.
- Миттєва перевірка з поясненням.
- Таймер і прогрес.
- Підсумковий бал, відсоток, час та аналіз помилок.
- Завантаження TXT, копіювання звіту, друк/збереження у PDF через браузер.
- Адаптивна зелена стімпанк-стилістика.
- Не потребує сервера, зовнішніх бібліотек чи інтернету.

Відповіді обробляються локально у браузері й не надсилаються на сервер.
